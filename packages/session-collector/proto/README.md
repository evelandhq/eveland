# OpenTelemetry protocol definitions

This directory contains the trace, log, metric, resource, common, and
collector service definitions from
[`open-telemetry/opentelemetry-proto`](https://github.com/open-telemetry/opentelemetry-proto)
release `v1.11.0`.

The upstream files are licensed under Apache-2.0 and retain their original
copyright and license headers. Eveland loads these definitions with
`protobufjs`; the protocol wire format is not implemented locally.
