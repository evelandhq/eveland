---
title: Eve 兼容性
description: 理解 Eveland 已验证的 Eve 版本窗口与 Fail-closed Policy。
---

在 Eve 发布稳定 Compatibility Contract 之前，Eveland 支持最近三个经过完整验证的 Eve Minor Line。当前代码中的产品契约支持 `0.25.x`、`0.26.x` 与 `0.27.x`，验证版本为 `0.25.3`、`0.26.2` 与 `0.27.3`。

UI 仅将最新支持线 `0.27.x` 标为绿色。较旧但仍受支持的版本保持可运行，不过会以红色显示并提醒升级；不受支持的版本同样显示为红色且继续阻断。

Eve 0.27 将 Nuxt 部署迁移到 Vercel 稳定 Services Model，改善 Compaction 与 Prompt Cache，并让 Route Auth 返回符合标准的 Challenge。HTTP Basic 现在声明 Realm 与 UTF-8 Charset，并在 Unicode NFC 规范化后比较 Credential。Eveland 不通过 Eve 的 Nuxt Integration 托管导入的 Agent，也不会根据 401 Challenge 推断 Connection Method，因此不需要新增 Adapter 分支。

0.27.1–0.27.3 Patch 改善了 Workflow 并发与取消、队列化 Channel Delivery、Slack/Teams Routing、带 Prefix 的 Callback Route、Dynamic Tool 刷新、Sandbox Seed 写入顺序和 Diagnostic。Eve 0.27.2 还会在打开 NDJSON Stream 时先发送一个空白字节，并允许 Client Caller 显式关闭自动 Stream Reconnect。Eveland 的 Stream Monitor 已忽略空行，Gateway 会无缓冲透传该字节，Playground 则保留默认的 Durable Reconnect 行为。经验证窗口内的 canonical session/continuation/cancel/stream Route、Vercel OIDC Header、Observer Hook Event、Schedule/Channel 定义和 `SandboxBackend` 契约保持兼容。

即使 `^0.27.0` 等 Range 已允许新 Patch，Agent 项目也应刷新 Lockfile 并重新部署，才能实际获得 `0.27.3`。Eve 0.27.3 同时要求 AI SDK `ai@^7.0.34`；若项目单独钉死或锁定了更旧的 AI SDK，应一并升级。自定义 NDJSON Consumer 必须忽略空行；如果 Relay/Proxy 自己管理重连，可以使用 Eve 新增的显式 Reconnect Opt-out，普通 Agent Client 应保留默认行为。

仅有 npm Publication 不会扩大窗口。新 Minor 只有在 Changelog/Source Review 与完整 Compatibility Matrix 通过后才进入；进入时会有意识地移除较旧 Minor。

## Enforcement Point

依赖缺失、超出窗口或无法证明兼容时，Eveland 会在以下位置 Fail Closed：

- Source Import 与 Preflight
- Build 与 Restart
- Cold Activation
- Playground Traffic
- Public Session Create、Continue、Cancel 与 Stream
- Schedule Execution

Diagnostic 会要求项目 Owner Upgrade，而不是猜测旧 Protocol。生产环境升级 Eve 或 Eveland 前都应阅读 Release Note。
