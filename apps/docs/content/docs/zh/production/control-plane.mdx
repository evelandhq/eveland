title: 安装控制面
description: 安装稳定 Eveland Release 并启动 Web、API、Gateway 与 Postgres。
---

稳定安装必须使用精确的 `vX.Y.Z` Tag，不要将可变的 `main` Checkout 当作稳定实例部署。

## 安装指定版本

```bash
git fetch --tags origin
git checkout vX.Y.Z
pnpm install --frozen-lockfile
pnpm --filter @eveland/api db:migrate
```

## 配置生产身份

为 Web、API、Gateway 与 Worker 设置相同的 `EVELAND_REVISION`，并设置 `EVELAND_RELEASE_CHANNEL=stable`。Better Auth、应用加密、Gateway Service Authentication、Affinity 签名与 Scheduler Authentication 必须使用彼此独立的 Secret，不能沿用开发 Fallback。

启动前配置公开 Web/API Origin、必要时的 Cookie Domain、共享绝对数据目录、数据库 URL 与 Agent Base Domain。

## 启动控制面

使用生产 Overlay；它启动 Web、API、Gateway 与 Postgres，不启动容器化 Worker：

```bash
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d
```

确认 Web 与 API 显示相同的 Build Identity。控制面只有在 API 与 Gateway `/health` 返回一致的产品版本、Revision 与 Release Channel 后才算就绪。
