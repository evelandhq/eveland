Eveland separates its control plane from public agent traffic and from the privileged host runtime controller.

<RuntimeTopology />

## Application boundaries

| Application | Responsibility |
| --- | --- |
| Web | Human control panel for projects, deployment, Playground, sessions, usage, source, secrets, and logs. |
| API | Control-plane HTTP contract, persistence, import handling, and embedded observer collection. |
| Gateway | Host-routed public Agent data plane, session affinity, streaming, and internal Playground path. |
| Worker | Job consumer that builds, starts, stops, restarts, and cleans up deployments. |

Applications do not import one another. Shared contracts and persistence live in packages:

```text
apps → packages
packages/db → packages/core
packages/core → no other Eveland package
apps -X→ apps
```

## Data paths

Control-plane state lives in Postgres. Imported sources, prepared releases, encrypted environment files, observer outboxes, and sandbox caches live below the configured Eveland data directory.

The observer hook writes durable envelopes into a deployment-specific outbox. API’s embedded collector claims, validates, and projects them into sessions and usage records exactly once.

## Trust boundaries

- Gateway handles public request bodies but cannot access imported project data.
- API encrypts secrets and never returns their values.
- Worker owns the runtime controller and builds untrusted project dependency trees inside the configured build sandbox.
- Production deployments run under an unprivileged user with systemd filesystem, privilege, CPU, and memory restrictions.
- Agent execution uses the injected bubblewrap sandbox backend and a project-specific durable cache.

## Request path

```text
Client
  → wildcard HTTPS host
  → Traefik
  → Gateway
  → route policy + session binding
  → private deployment port
  → Eve HTTP channel
```

Gateway preserves the Agent’s own authorization headers, cookies, request body, and streaming response. It routes traffic; it does not replace the Agent’s application authentication.
