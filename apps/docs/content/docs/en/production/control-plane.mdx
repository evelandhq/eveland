---
title: Install the control plane
description: Install a stable Eveland release and start Web, API, Gateway, and Postgres.
---

Stable installations use an exact `vX.Y.Z` tag. Do not deploy a mutable `main` checkout as a stable instance.

## Install the selected release

```bash
git fetch --tags origin
git checkout vX.Y.Z
pnpm install --frozen-lockfile
pnpm --filter @eveland/api db:migrate
```

## Configure production identity

Set `EVELAND_RELEASE_CHANNEL=stable` and the same `EVELAND_REVISION` for Web, API, Gateway, and Worker. Configure independent values for Better Auth, application encryption, Gateway service authentication, affinity signing, and scheduler authentication. Never reuse the development fallbacks.

Set the public Web/API origins, cookie domain when required, the shared absolute data directory, database URLs, and Agent base domains before startup.

## Start the control plane

Use the production overlay, which starts Web, API, Gateway, and Postgres but not the containerized Worker:

```bash
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d
```

Confirm Web and API report the same build identity. API and Gateway `/health` responses must agree on product version, revision, and release channel before the control plane is considered ready.

Next, [install the host Worker](/docs/production/worker).
