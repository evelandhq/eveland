**在你自己的基础设施上运行 100 个 agent。**

这是 Eveland 的核心定位：既要支持以十倍、百倍于团队人数的规模运行 Agent 舰队，又要让它们直接运行在企业自己的基础设施和数据环境内。

## 一百个 agent，而不是一个

认真使用 agent 的组织，最终手里不会只有*一个* agent。重复性工作存在于
每个职能里——客服、市场、行政、财务——每一处都配得上一个自己的 agent。
稳态就是 agent 数量超过人数。

这个比例会压垮为“单数”设计的工具。每个 agent 一条部署流水线、一个登录
页、一个聊天前端、一块监控面板——乘以一百之后没有一样能活下来。Eve 默认
的自托管方案是单节点跑单个 agent：跑*一个* agent 很好，跑一支舰队则无从
谈起。Eveland 从第一行代码就为复数而建：导入一个项目，部署、路由、
密钥、定时、身份、聊天、观测全都已经在那里——平台级共享一次，而不是每个
agent 重建一遍。

这也是平台追求[运行时密度](/zh/docs/reference/design/runtime)的原因：一百
个 agent 共享一台机器时，基础设施消耗的每一份资源，都是一个你跑不了的
agent。

## 在你的基础设施上，而不是别人的

“数据主权”是宏观层面的考量，但在实际业务中原因更现实：**agent 只有在你的系统
所在之处才有用。**SaaS 应用可以住在云端，但没有哪家企业的一切都在云上
——财务数据、经营数据、自托管的内部应用。够不到这些系统的 agent 干不了
活，而强迫内部系统迁移到托管平台上的成本以年计——如果可行的话。这不是
特定地域的现实；异构、部分本地化的系统版图是全球企业的常态。Eveland 走向
数据已经在的地方。

然后是成本，两种货币：

- **运行成本。** LLM 调用、workflow 状态、沙箱执行——在托管平台上每一项都是
  计量账单；在自己的硬件上它们是你已经拥有的容量，而平台的工程目标就是
  一点都不浪费。通过[systemd 运行时密度](/zh/docs/reference/design/runtime)、
  [轻量 bubblewrap 沙箱](/zh/docs/reference/design/sandbox)、
  [按需激活与缩容到零](/zh/docs/reference/design/scale-to-zero) 以及
  [外置 Workflow 调度](/zh/docs/reference/design/workflow)，一台普通主机
  就能从容承载数十个生产级 Agent。
- **管理成本。** 托管部署平台是为运维人员建的；业务人员看不到 agent 到底
  做了什么。Eveland 给开发、运维和业务同一扇清晰的窗：Session、推理链路、
  工具调用、定时与用量都是一等的、可读的界面——而不是等谁来要再导出的
  原始日志。底层由[透明的 OpenTelemetry 遥测管道](/zh/docs/reference/design/observability)与
  [安全 Agent Gateway](/zh/docs/reference/design/gateway)统一保障。

## Eveland 从哪里来

通往真正自主运行的 agent 的路很长，我们走过其中大半：无法脱手运行的
框架、失败时不稳定也无从追溯的运行器，以及中间的好几站。
[Eve](https://eve.dev) 是第一个符合我们期待的框架——agent 即代码、可
追溯、稳定运行、跨 LLM、跨云，适合以组织规模运行。Eveland 是缺失的
生产那一半：从“agent 本地能跑”到“组织在生产环境稳定跑在它上面”之间的一切。

这不是纸上设计。[金数据](https://jinshuju.net)在 Eveland 上运行着 20+
个 agent——客服、市场、行政、财务——已连续稳定运行超过两个月。这里记录
的大多数[设计决策](/zh/docs/reference/design)都是被那个生产现实逼出来
的，而不是预先想象的。

## 给谁用

任何有重复性业务流程的团队。写 agent 需要一点开发能力，但在如今的编码
agent 帮助下，这道门槛在持续降低——一人公司可能受益最大：你不干活的
时候，agent 在干。

与办公聊天助手相比，差别是无需值守的自主性——Eveland 的 agent 按 schedule
运行、被 webhook 和 channel 唤醒，不需要有人盯着才存在。与自拼的
agent 运行器相比，差别是那个朴素的词：生产。稳定运行、严格隔离、第一公民
可观测性，出了问题有确定性的追溯与恢复机制。

如果这正是你的问题，[部署平台](/zh/docs/production)，给你的第一个一百
个 agent 一个家。
